# Identidade visual — arquivos da marca

Os arquivos desta pasta são **provisórios e neutros**. Ao receber os arquivos oficiais da FAVIS:

1. Substitua `icon.svg`, `icon-192.png` e `icon-512.png` (ícones do app/PWA).
2. Adicione o logotipo como `logo.svg` (e `logo-dark.svg`, se houver) e ajuste `src/components/layout/brand.tsx`.
3. Ajuste as cores e a tipografia em `src/styles/brand.css` (tokens `--brand-*`).
